## Diabetes Risk Prediction System
A Python-based Diabetes Risk Prediction System that uses a dummy dataset of 15 patient records to classify diabetes risk as low, moderate, or high. It analyzes this prediction using factors such as age, BMI, blood glucose, and family history.

## Features
- Dummy dataset containing 15 patient records
- Risk assessment based on age, BMI, glucose level, and family history
- Rule-based prediction
- Interactive menu to analyze patients and check new entries

## Technologies Used
- Python
- Pandas

## Installation

Install the required library:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python diabetes_prediction.py
```

## Disclaimer
This project is for educational purposes only. It does not provide medical diagnoses.
